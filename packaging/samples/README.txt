moonBASIC samples
=================

Open any .mb file in the IDE (File → Open, or File → Open Samples Folder),
then press F5 to run.

  hello.mb       — window + text
  spin_cube.mb   — simple 3D cube

You do not need to clone the GitHub repo for these. More examples:
  https://github.com/CharmingBlaze/moonbasic/tree/main/examples
